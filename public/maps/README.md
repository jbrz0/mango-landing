# Basemap attribution

`countries-110m.json` is the world-atlas v2 1:110m countries TopoJSON dataset, downloaded from https://cdn.jsdelivr.net/npm/world-atlas@2/countries-110m.json.

The source geometry is Natural Earth, in the public domain: https://www.naturalearthdata.com/about/terms-of-use/.

The frontend projects it with d3-geo. Markers denote editorial regions and filtering controls; they do not represent live geolocated incidents. Connecting arcs illustrate cross-market relationships, not measured capital flows.
